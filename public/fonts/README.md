# Locally served typefaces

Inter and Outfit are served from this site's `/fonts` directory, so page views do not request Google Fonts resources.

Retrieved 2026-10-30 from the Google Fonts source repository over HTTPS:

- https://github.com/google/fonts/tree/main/ofl/inter
- https://github.com/google/fonts/tree/main/ofl/outfit

The original SIL Open Font License files are included as `inter-OFL.txt` and `outfit-OFL.txt`. Keep the notices with redistributed font files. The website declares the local faces in `app/fonts.css`.
